# Flakeglee

Invent a Word We Need — a [make.fun](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) competition entry.

**Flakeglee** — the quiet joy of a cancelled plan you secretly hoped would fall through.

English has no word for that secret relief when plans fall through — the flake who cancels gives you glee. "Flake + glee" is sayable, spellable, and memorable, and the definition lands in one reading.
